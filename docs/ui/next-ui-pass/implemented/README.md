# Новый UI неизменяемых списков

Общий каркас применён к продуктам, поставщикам, документам, декларациям, транзакциям, расходам и другим экранам на `ImmutableTableBox`.

## Что изменено

- Поиск, создание и экспорт собраны в одной панели.
- В пустом поиске оставлена только иконка лупы. Поле занимает всё свободное место.
- У поля нет жёсткой высоты и предела ширины, поэтому введённый текст не обрезается.
- Поле поиска принимает ввод сразу после перехода во вкладку. Нажимать на поле не нужно.
- Поиск не зависит от регистра. В продуктах он охватывает ID, название, поставщика, тип, дату, SN и комментарий.
- Совпавший текст подсвечивается внутри ячеек.
- Таблица заполняет ширину окна, но узкая колонка выбора не растягивается.
- Шапка и строки стали нейтральнее и плотнее. Акцент оставлен для действий, выбора и совпадений.
- Выбранная строка оформлена как в варианте A: тёмная бронзовая заливка, тонкая рамка и небольшое скругление.
- В шапке колонки выбора стоит флажок для всех показанных строк.
- Панель выбора получила тексты «Выбрано: N» и «Снять выделение».
- Загрузка, ошибка, пустой список и пустой ответ поиска остаются внутри общего блока таблицы.

## Что сохранено

- Библиотека `table-core:1.10.0` не заменялась.
- Новая библиотека таблиц и `table-paging` не добавлялись.
- Фильтры колонок, сортировка, ширина и порядок колонок, открытие строки, выбор и экспорт сохранены.
- Скрытия колонок, счётчика строк и пагинации нет.
- База данных, репозитории, навигация, mutable-таблицы, аналитика и storage не менялись.

## Проверка

- Финальные скриншоты шести списков проверены в исходном размере окна 1280 × 800.
- После перехода в «Продукты» запрос `47` введён без клика по поиску: список сократился до одной строки, совпадение в ID подсветилось.
- `Esc` очистил запрос и вернул полный список.
- Проверены выбор только показанной строки, сброс поиска и сохранение выбора.
- Тесты модуля прошли командой `./gradlew :features:table:immutable:desktopTest`.

Не запускались опасные действия удаления и принудительные состояния ошибки. Экспорт проверен на уровне общего пути данных и сборки, без сохранения итогового файла через диалог.

# Принятый UI и готовые экраны

Этот файл — точка входа для следующего UI-агента. Сначала читать его, затем открывать только код выбранного экрана.

## Общие принципы

- Сначала иерархия и читаемость, затем декор.
- Основные поверхности нейтральные. Цвет обозначает смысл, выбор или действие и не заливает большие зоны без причины.
- Длинные русские подписи не обрезать: давать им ширину или перенос до двух строк.
- Не задавать жёсткую ширину без причины. Для боковых панелей применять диапазон ширины и оставлять основной части окна свободное место.
- Загрузка, ошибка, пустой список и пустой поиск живут внутри общего каркаса экрана.
- Полосы прокрутки должны быть доступны, но не спорить с данными.
- Не менять состав данных, навигацию и действия при чистой UI-правке.
- Не переносить механику неизменяемых таблиц в формы, аналитику, журнал или служебный экран.
- Проверять живые данные и длинные подписи при 1280 × 800 и большом окне. Если агент не управляет окном надёжно, снимок просить у пользователя.

## Что уже готово

- Single-формы и связанные карточные блоки прошли отдельный UI-проход.
- Неизменяемые списки на `ImmutableTableBox` получили общий каркас.
- Экран «Оповещения» переведён на двухпанельный вид.

# Неизменяемые списки

Общий каркас применён к продуктам, поставщикам, документам, декларациям, транзакциям, расходам и другим экранам на `ImmutableTableBox`.

## Что изменено

- Поиск, создание и экспорт собраны в одной панели.
- В пустом поиске оставлена только иконка лупы. Поле занимает всё свободное место.
- У поля нет жёсткой высоты и предела ширины, поэтому введённый текст не обрезается.
- Поле поиска принимает ввод сразу после перехода во вкладку.
- Поиск не зависит от регистра. Совпавший текст подсвечивается внутри ячеек.
- Таблица заполняет ширину окна, но узкая колонка выбора не растягивается.
- Шапка и строки нейтральные и плотные. Акцент оставлен для действий, выбора и совпадений.
- В шапке колонки выбора стоит флажок для всех показанных строк.
- Панель выбора получила тексты «Выбрано: N» и «Снять выделение».
- Загрузка, ошибка, пустой список и пустой ответ поиска остаются внутри блока таблицы.

## Что сохранено

- Библиотека `table-core:1.10.0` не заменялась.
- Новая библиотека таблиц и `table-paging` не добавлялись.
- Фильтры, сортировка, ширина и порядок колонок, открытие строки, выбор и экспорт сохранены.
- База данных, репозитории, навигация, mutable-таблицы, аналитика и storage не менялись.

## Проверка и снимки

- Шесть списков проверены при 1280 × 800.
- Тесты прошли командой `./gradlew :features:table:immutable:desktopTest`.
- `products-list-after.png` — список продуктов после правки.
- `products-list-search-highlight.png` — поиск и подсветка совпадения.
- `products-list-selection-after.png` — выбранная строка.
- `immutable-lists-after-contact-sheet.png` — шесть списков на общем каркасе.

# Оповещения

Принят вариант Б с боковым выбором уровня.

## Что изменено

- Слева оставлены три уровня: «Срочные», «Важные» и «Прочие». Пункта «Все» нет.
- Справа показаны группы и их записи.
- Группы по умолчанию свёрнуты; раскрытие и переход по записи сохранены.
- Красный, жёлтый и зелёный цвета служат метками уровня. Текст «Срочно» в строках не выводится.
- Счётчик уровня суммирует все записи всех групп этого уровня: `3 + 2 + 1 = 6`.
- Шторка и экран берут одну и ту же сумму уровня.
- Заголовок группы показывает число записей только в этой группе.
- Пустой уровень показывает `0` и отдельный пустой вид.
- База данных, публичный API и навигация не менялись.

## Проверка и снимок

- Пользователь проверил экран на живых данных.
- `notifications-after.png` — финальный вид из приложения при 1920 × 1080. На снимке группа раскрыта вручную, чтобы были видны строки; начальное состояние группы свёрнутое.
- Сборка и `:features:notification:desktopTest` не запускались по просьбе пользователя.

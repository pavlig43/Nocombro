# Следующий проход по UI

Завершены три зоны:

- карточный проход single-форм;
- общий каркас неизменяемых списков;
- экран «Оповещения».

## Где смотреть

- `implemented/README.md` — принятые UI-принципы, готовые экраны и их проверка;
- `implemented/` — финальные снимки из приложения;
- `proposals/` — принятые и отклонённые макеты;
- `master/` и `current/` — история, не источник текущего вида;
- `TASK.md` — задание для следующего UI-прохода.

## Что не надо переделывать

Не предлагать заново single-формы, неизменяемые списки и «Оповещения». Не переносить механику `ImmutableTableBox` в экран иного типа только ради единого вида.

## Что осталось

Для следующего выбора остались «Аналитика», «Прибыльность», «Пример таблицы», «Склад», «Эксперименты» и «Доктор». Экран надо выбрать по видимым помехам работе, а не по желанию обновить всё подряд.

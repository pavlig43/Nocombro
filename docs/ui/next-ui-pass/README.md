# Следующий проход по UI

Выбрана одна следующая зона после single-форм: списки на базе `ImmutableTableBox`.

- `master/` — вид до правок single-форм.
- `current/` — готовые single-формы и пока старые списки.
- `comparison/` — пары для сверки стиля.
- `concept/` — два PNG-варианта списка продуктов.
- `TASK.md` — готовое задание для агента.

Рекомендован вариант A: плотная таблица. Список продуктов служит пилотом для общего вида неизменяемых списков.

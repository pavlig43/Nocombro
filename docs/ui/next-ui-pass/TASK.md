# Задача: общий новый UI неизменяемых списков

## Цель

Взять вариант A из `concept/products-list-a-compact-table.png` и перенести его на общий каркас неизменяемых списков.

Это одна общая фича для продуктов, поставщиков, документов, деклараций, транзакций, расходов и остальных экранов на `ImmutableTableBox`. Продукты — первый экран для настройки внешнего вида и первого скрина, а не отдельная реализация.

Вариант B пока не делать: боковая карточка повторяет форму и требует нового состояния выбора.

## Архитектура и названия

- Менять общий `ImmutableTableBox` и связанные общие компоненты.
- Не делать копию таблицы или отдельный режим для продуктов.
- Не использовать названия `CompactWorkbench`, `Legacy` и `uiMode`.
- Использовать названия в стиле проекта: `ImmutableTableBox`, `ImmutableTableToolbar`, `TableBox`, `SelectionActionBar`.
- Особенности поиска таблицы передавать через простой контракт вроде `SearchMatcher`.

## Панель над таблицей

В одной строке: поле поиска, главная кнопка создания и меню экспорта.

Не добавлять текст «Показано X из Y», любой счётчик строк, меню колонок, скрытие колонок и элементы пагинации.

## Поиск

Поиск общий для всех неизменяемых списков и не зависит от регистра.

Для продуктов искать по ID, названию, поставщику, отображаемому названию типа, отображаемой дате, SN и комментарию.

Для остальных списков искать по отображаемому тексту всех содержательных колонок. Не учитывать колонку выбора и служебные значения.

Правила:

- обрезать пробелы по краям и искать вхождение подстроки;
- пустой запрос показывает все строки;
- использовать тот же текст, который видит пользователь, включая формат даты и название типа;
- не искать по сырому `enum.toString()` или `model.toString()`;
- порядок обработки: фильтры колонок → общий поиск → сортировка;
- поиск не сбрасывает выбор, фильтры, сортировку, ширину и порядок колонок;
- экспорт получает строки после фильтров и поиска, в текущем порядке.

## Ввод без фокуса

После открытия вкладки пользователь может сразу печатать, не нажимая на поле поиска.

- Первый печатный символ добавляется в запрос, переводит фокус в поле, не теряется и не дублируется.
- `Backspace` удаляет последний символ, `Esc` очищает запрос.
- Не перехватывать сочетания с `Ctrl`, `Alt`, `Meta` и системные сочетания.
- Не перехватывать ввод, если фокус уже в другом поле, фильтре, диалоге или меню.
- Подписывать на `KeyEventHandler` только активный экран списка; при уходе или уничтожении компонента отписываться.
- Проверить русскую и английскую раскладки.

Использовать существующую цепочку `Window(onKeyEvent = KeyEventHandler::handle)`, не добавлять второй глобальный обработчик.

## Подсветка совпадений

Подсветка обязательна.

- Подсвечивать все совпавшие части текста внутри ячейки без учёта регистра, а не всю строку.
- Для ID, типа и даты подсвечивать отображаемый текст.
- При пустом запросе подсветки нет.
- Выделение выбранной строки не должно сливаться с подсветкой поиска.
- Цвета брать из `MaterialTheme`, например `primaryContainer` / `onPrimaryContainer`. HEX не копировать.
- Сделать один общий composable для текста с подсветкой. Не хранить отдельный запрос в каждой ячейке.

## Вид таблицы

- Одна `Surface` вокруг таблицы и обеих полос прокрутки, с тонкой рамкой и скруглением 20–22 dp.
- Нейтральная шапка. Основной цвет оставить для создания, активной сортировки и фильтра, выбранной строки и подсветки.
- Плотные строки без отдельных карточек.
- Кнопку создания перенести из первой колонки в панель.
- В заголовке колонки выбора поставить checkbox «выбрать все показанные строки».
- Панель выбора: «Выбрано: N», удаление и сброс выбора.
- Сохранить открытие строки, фильтры, сортировку, изменение ширины и порядка колонок.

Загрузка, ошибка, пустой список и отсутствие совпадений остаются внутри одного каркаса. Тексты: «Записей пока нет» и «Ничего не найдено».

## Размеры

- внешний отступ: 16 dp;
- зазор между панелью и таблицей: 12–16 dp;
- скругление крупных блоков: 20–22 dp;
- кнопки и поля: 44–48 dp;
- шапка таблицы: около 48 dp;
- строка таблицы: около 44 dp;
- сетка отступов: шаг 8 dp.

## Библиотеки и границы задачи

- Оставить `table-core:1.10.0`.
- Использовать уже подключённый `table-format:1.10.0`, если он помогает с отображением.
- Не подключать `table-paging`: списки загружаются целиком, пагинации сейчас нет и в этой задаче она не нужна.
- Не добавлять новую библиотеку таблиц.
- Не менять БД, репозитории, навигацию, удаление и набор колонок.
- Не менять mutable-таблицы, аналитику и storage. Если потребуется правка `TableBox`, новые параметры должны сохранить прежнее поведение по умолчанию.

## Где менять

- `features/table/immutable/src/desktopMain/kotlin/ru/pavlig43/immutable/internal/ui/ImmutableListBox.kt` — общий каркас и состояния.
- Новый `ImmutableTableToolbar.kt` рядом — поиск, создание и экспорт.
- `features/table/immutable/src/desktopMain/kotlin/ru/pavlig43/immutable/internal/ui/SelectionActionBar.kt` — выбор и русский текст.
- `features/table/immutable/src/desktopMain/kotlin/ru/pavlig43/immutable/internal/component/ImmutableTableComponent.kt` — запрос и порядок фильтры → поиск → сортировка.
- Общие помощники колонок — отображаемый текст и подсветка.
- `features/table/core/src/desktopMain/kotlin/ru/pavlig43/tablecore/ui/TableBox.kt` и desktop scrollbar — только при необходимости и обратно совместимо.

## Проверка

Автотесты: каждое поле продукта; регистр; русский и английский текст; пробелы; пустой запрос; фильтры + поиск + сортировка; сохранение выбора; отображаемые тип и дата; одно и несколько совпадений; первый символ; `Backspace`; `Esc`; отсутствие перехвата другого ввода и сочетаний клавиш.

Вручную на всех неизменяемых списках проверить создание, открытие, фильтры, сортировку, выбор всех показанных строк, удаление, сброс выбора, повтор после ошибки, экспорт найденных строк, длинные и пустые значения, загрузку, ошибку, пустой список и поиск без совпадений. Размеры окна: 1936 × 1096 и 1280 × 800.

```powershell
.\gradlew :features:table:core:compileKotlinDesktop :features:table:immutable:desktopTest
```

# Концепты списка продуктов

Исходник: `../current/current-04-products-list.png`.

## A — плотная таблица

`products-list-a-compact-table.png` — рекомендованный вариант. Он сохраняет плотность данных, но даёт экрану ясные блоки: панель действий, таблицу и нижнюю строку.

## B — быстрый просмотр

`products-list-b-split-preview.png` — справа показана карточка выбранного продукта. Вариант удобен для чтения, но повторяет часть формы, съедает ширину и требует нового состояния выбора. Его лучше оставить на потом.

PNG задают сетку, размер блоков, цвет и акценты. Текст строк и набор колонок условны: при правке брать их из кода.

Оба PNG созданы встроенным `imagegen` в режиме `ui-mockup`. Краткие запросы лежат в `PROMPTS.md`.

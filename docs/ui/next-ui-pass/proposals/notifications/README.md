# Оповещения

Источник: ветка `ui/next-ui-pass`, основа `dd7f6039`. Макеты сделаны по экрану с тремя оповещениями об экспериментах.

## Вариант А — фильтры сверху

Отклонён. Фильтры занимают одну строку и оставляют всю ширину длинным подписям, но хуже отделяют уровни от списка.

## Вариант Б — фильтры слева

Принят и перенесён в код. Слева оставлены только «Срочные», «Важные» и «Прочие», без пункта «Все». Цвет показывает уровень, поэтому подпись «Срочно» в строках не нужна. Группы по умолчанию свёрнуты.

Сохранены сворачивание группы, переход по записи, состав данных и навигация. Счётчики уровня теперь суммируют записи всех групп, а заголовок группы показывает её собственное число.
